# Protein-Stability-Colabs
Google Colab implementations of recent methods to predict mutation-induced protein stability changes.

This repository mostly hosts Google Colab Notebooks which implement several recent methods to predict mutation-induced protein stability changes. 
They are designed to rum in Google Colab environment (GPU or CPU as applicable), often optimized for a higher speed, and produce [ThermoMPNN-style](https://colab.research.google.com/drive/1OcT4eYwzxUFNlHNPk9_5uvxGNMVg3CFA#scrollTo=S8YplqMTaE_x) mutational landscape outputs.
